   * **Problema:** Um usuário com perfil `Aluno` conseguiu listar todos os projetos da base ao acessar a rota `/projetos`.

2. **[MÉDIO] Falha de Validação e Experiência do Usuário na Edição de Cronogramas (Cenário B - Regra 3):**

### 💡 Recomendações de Correção

#### 1. Correção de Isolamento de Dados (Flask + SQLAlchemy)
Aplique a filtragem por escopo no endpoint `/projetos` utilizando o identificador do grupo presente na sessão do usuário autenticado:

```python
from flask import abort
from flask_login import current_user, login_required

@app.route('/projetos', methods=['GET'])
@login_required
def listar_projetos():
    if current_user.role == 'aluno':
        if not current_user.grupo_id:
            abort(403, description="Aluno não vinculado a um grupo.")
            
        # Garante o isolamento estrito por grupo
        projetos = Projeto.query.filter_by(grupo_id=current_user.grupo_id).all()
    elif current_user.role in ['admin', 'gestor']:
        projetos = Projeto.query.all()
    else:
        abort(403)
        
    return render_template('projetos.html', projetos=projetos)
```

#### 2. Proteção contra Acesso Indevido (RBAC para Regra 2)
Implementar decoradores customizados para bloquear alunos em rotas restritas:

```python
from functools import wraps

def role_required(*roles_permitidas):
    def decorator(f):
        @wraps(f)
        def decorated_function(*args, **kwargs):
            if current_user.role not in roles_permitidas:
                abort(403, description="Acesso restrito ao perfil de gestão.")
            return f(*args, **kwargs)
        return decorated_function
    return decorator
```

#### 3. Ajuste de Validação de Datas (Flask-WTF / Marshmallow)
Ajustar o validador para garantir que datas retroativas inválidas sejam rejeitadas com mensagens claras, sem travar alterações legais:

```python
from datetime import date
from wtforms.validators import ValidationError

class CronogramaForm(FlaskForm):
    data_inicio = DateField('Data Início', validators=[DataRequired()])
    data_fim = DateField('Data Término', validators=[DataRequired()])

    def validate_data_fim(self, field):
        if field.data < self.data_inicio.data:
            raise ValidationError("A data de término não pode ser anterior à data de início.")
        if field.data < date.today():
            raise ValidationError("Não é permitido definir um prazo de conclusão retroativo.")
```
